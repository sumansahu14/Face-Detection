# Face Detection and Attendance System

## 📌 Project Overview

This project is a face detection, face recognition, and attendance management system developed using Python and computer vision techniques.

The system detects faces using OpenCV and recognizes registered faces using a trained deep learning model. It can also be used to record attendance.

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Keras / TensorFlow
- Jupyter Notebook
- Haar Cascade Classifier
- Excel for attendance records

## ✨ Features

- Face detection using OpenCV
- Face recognition using a trained model
- Face data collection
- Data consolidation
- Attendance recording
- Real-time camera-based recognition

## 📂 Project Files

- `data_collect.ipynb` — Collects face data.
- `consolidate_data.ipynb` — Processes and consolidates collected data.
- `recognize_attendance.ipynb` — Performs face recognition and attendance processing.
- `final_model.h5` — Trained machine learning model.
- `haarcascade_frontalface_default.xml` — Haar Cascade classifier used for face detection.

## ▶️ How to Run

1. Install the required Python libraries.
2. Open the Jupyter Notebook files.
3. Run the data collection notebook to collect face data.
4. Run the data consolidation notebook.
5. Use the recognition and attendance notebook to detect and recognize faces.

## 🎯 Project Goal

The goal of this project is to demonstrate the use of computer vision and machine learning for automated face recognition and attendance management.
